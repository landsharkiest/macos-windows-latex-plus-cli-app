## User Journey

### First Launch
```
1. Double-click app icon
   └─> Splash screen (2.5s)
       └─> Main window opens
           ├─> Check LaTeX status
           ├─> Check AI status
           └─> Show welcome message
```

### Creating a Document
```
1. Write LaTeX code in editor
   ↓
2. Click "Compile" button
   ↓
3. App compiles with pdflatex
   ↓
4. PDF opens automatically
   ├─> * Success: "Compiled successfully"
   └─> X Error: Shows error message
```

### Using AI
```
1. Click "AI Generate"
   ↓
2. Enter description
   ↓
3. Click "Generate"
   ↓
4. AI generates LaTeX code
   ↓
5. Code appears in editor
   └─> Ready to compile or edit
```
