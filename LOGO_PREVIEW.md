## Logo Description

### Visual Appearance

```
     ┌─────────────────────────────────┐
     │   ╭──────────────────────╮      │
     │   │   Purple Gradient    │      │
     │   │     Background       │      │
     │   │                      │      │
     │   │       ┌─┐            │      │
     │   │       │T│            │      │
     │   │       ├─┤  e[*]       │      │
     │   │       │ │    x       │      │
     │   │       │ │            │      │
     │   │        [Pen]        │      │
     │   │       ___            │      │
     │   │                      │      │
     │   ╰──────────────────────╯      │
     └─────────────────────────────────┘

   LaTeX "TeX" Symbol with AI Elements
```

### Design Elements

1. **Large "T"** (White)
   - Vertical and horizontal bars
   - Rounded corners
   - Represents LaTeX typography

2. **Subscript "e"** (Gold)
   - Teardrop/diamond shape
   - Circuit connection lines
   - Represents electrical/tech theme

3. **Superscript "X"** (Gold)
   - Crossed diagonal bars
   - Neural network dots at corners
   - Represents AI intelligence

4. **Pen/Pencil** (White with gold tip)
   - Below the text
   - Document lines underneath
   - Represents writing/editing

5. **Background**
   - Circular gradient (#667eea → #764ba2)
   - Decorative circuit elements
   - Drop shadow for depth

### Color Codes

- **Primary Purple**: `#667eea` (102, 126, 234)
- **Deep Purple**: `#764ba2` (118, 75, 162)
- **Gold**: `#ffd700` (255, 215, 0)
- **Light Gold**: `#ffed4e` (255, 237, 78)
- **White**: `#ffffff` (255, 255, 255)

### Design Philosophy

The logo combines:
- **Academic**: Classic TeX typography
- **Modern**: Smooth gradients and rounded shapes
- **Tech**: Circuit patterns and AI elements
- **Professional**: Clean, balanced composition
- **Accessible**: High contrast, readable

### Viewing Instructions

**In Browser:**
```bash
# Open in default browser
open assets/icons/logo.svg          # macOS
start assets/icons/logo.svg         # Windows
```

**In VS Code:**
- Right-click SVG file → Open Preview

**In Figma/Sketch:**
- Import SVG file for editing

**As PNG:**
```bash
# Generate PNG first
node assets/generate-icons-sharp.js

# Then view
open assets/icons/icon-512.png
```
